Последний кадр ограничивает Compose-контент внутри более широкого окна эмулятора. Он проверяет переносы и доступность действий, а не конфигурацию системных панелей Android.

## Проверки

- 35 unit-тестов: пройдены.
- 15 UI-тестов: пройдены. Включают прямое подключение, подтверждение удаления, быстрый свет, единственную запись переключателя, отложенное применение яркости, доступность аксессуаров при движении и блокировку режимов, все категории, Back, выбор темы, поиск/raw, сохранение запроса между переходами, свежесть данных, ошибку быстрого действия, крупный шрифт, широкое окно и нулевой заряд.
- `lintDebug`: 0 ошибок; предупреждения по существующим SDK, зависимостям, manifest и рекомендациям KTX.
- `assembleDebug` и `assembleDebugAndroidTest`: успешно.
- Восемь основных цветовых пар карточек: контраст 7.01:1–12.38:1. Это проверка палитры, а не сертификация всех состояний доступности.
- `git diff --check`: без ошибок пробелов.

BLE-контроллер, протокол, модель состояния, security exchange, сохранение устройства и зависимости сборки совпадают с базой `3b82cd3`. Реальное управление колесом и TalkBack на телефоне в эту проверку не входили.

Полный [дизайн-код и устройство UI](../design-system.md). APK: `app/build/outputs/apk/debug/Ion-0.6.0-debug-v15.apk` от корня проекта. Текущая версия: 0.6.0-debug / versionCode 15. Код версии увеличен, чтобы APK обновлял ранее установленную 0.5.0 с versionCode 14 без понижения версии.
