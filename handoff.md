## Проверенный протокол замка V12 HT

1. Подключение, неподвижность + свежая телеметрия, MTU ≥ 44 (наблюдалось 247).
2. Запрос `AA AA 13 04 02 00 00 02 17` → валидный ответ `12 13 02 80 02` с 16 байтами; те же байты уходят в запросе `13 14 02 00 00 82` (получаются от текущего колеса, не хардкодятся, между сессиями не хранятся).
3. Ожидать строго `AA AA 12 04 02 80 82 01`; иначе lock не отправлять.
4. Один кадр: lock `AA AA 16 05 02 21 60 31 01 60`, unlock `AA AA 16 05 02 21 60 31 00 61`. ACK `... E0 31 00 E1` не заменяет read-back.
5. Read-back: SETTINGS byte39, mask `0x20` (1 = locked).

Guard STATIONARY пере-проверяется после security-обмена; повторов write нет; fallback — офф. приложение. Реализация: `LockSecurity.kt` + `BleController`. Read-back бит `0x20` найден диффом; подтверждён контрольными экспортами. Проверено на одном V12 HT / прошивке / телефоне; универсальность для других моделей не доказана.

## Оценка остатка пробега (2026-11-22)

- Остаток пути — telemetry **u16[28]/100** км (с оценкой колеса 48.00, без неё условные 180.00; совпадает с экраном колеса). Прежнее u16[26] = 95.00 при 100 % — не пробег.
- Переключатель: settings **byte40 бит 6 (`0x40`)** — найден before/after-диффом экспортов владельца. Запись `0x14/0x60 [0x3f, on]`: `_V12Cmd.remainderRangeEstimateCmd` = `0x3f` в ARM64-сборке офф. приложения (`tools/re/dispatch_range_estimate.py`, тот же поиск даёт известные 0x31/0x39; `docs/evidence/range-estimate-dispatch.txt`). Tier SAFE, подтверждение read-back. Запись на колесе ещё не проверялась.

## Звуки колеса

- Проигрывание: `0x14/0x60 [0x51, id, 0x01]` (как `playSound` в WheelLog), id 24 = `0x18` — гудок WheelLog на V12. Ion предлагает слоты 0–31: раньше было 0–15 + 24, а владелец слышал, что части звуков нет.
- **Названий в протоколе и APK нет**: что звучит в слоте, зависит от звукового пакета на колесе, а офф. приложение берёт имена с сервера вместе с паком (`/product/sound-pack/…`, `SoundItemModel`; в строках Dart есть только ключи UI). Поэтому имена задаёт райдер: долгое нажатие подписывает или скрывает слот (`SoundLabels`, prefs `sound_labels`). Когда владелец пришлёт список «слот → звук», можно зашить имена по умолчанию.
- Не сделано: смена паков и DIY-звуки (загрузка файла на колесо, `EzcanSoundFileUploadManager`/`EzCANSoundPackFileConfig`, `/download_soundPack_file.rmf`). Формат передачи не разобран.

## Подсветка (RGB-режимы и свои эффекты)

Источник: экспорты настроек владельца для каждого режима и PID-logcat офф. приложения при сохранении эффекта «testclaude» (2 кадра: все красные / все зелёные, 0,10 с). Кадры без токенов лежат в `docs/evidence/light-upload-frames.txt`; полный лог с токеном аккаунта хранится только в приватной папке research.
- **Режим** = settings byte 23: 0 выкл, 1 персональный, 2 музыка, 3 скорость. Цвет «музыки», вариант «скорости» и номер персонального эффекта в настройках не видны. Ion шлёт `0x33 [mode, ff ff ff ff]` для 0/2/3 и подтверждает их read-back байта 23. **Персональный** включается `0x33 [01, u32 id эффекта]` (в `genSetLightEffectModeMsg` четыре байта — пакет или цвет, 0xff = нет). Сам select `0x60 0x2d + id` меняет эффект только внутри персонального режима (проверено владельцем: из «музыки» он молчит, колесо даже не пищит). Поэтому кнопка ▶ шлёт select в персональном режиме и `0x33 01 id` в остальных; пункт «Персонализированная» включает последний включённый эффект (prefs `light_last_effect`) или первый на колесе; после загрузки, если колесо не в режиме 1, Ion досылает `0x33 01 id`. `0x33 01 id` пока не проверен на колесе.
- **Файл** `0:/light/diy/<id>.rgb` (LE): u32 формат=1, u32 id, u32 число кадров, u32 длина данных, u16 интервал в 10 мс, u16 «связь со скоростью»=20, далее кадры по **70 LED × RGB**. Цвет проходит кубическую кривую (выбранный 0x80 → 0x20, 0xFF → 0xFF; подтверждены только эти точки). CRC-32 (стандартный) совпал с захватом: `0x6401cc77`.
- **Загрузка** (адресная шина: источник 2, цель 0x21/0x00, канал, свойство): ping `16 [02 21 02]` → запрос хранилища `13 [02 00 05 01 00]` → open `0x81 [02, "…/<id>.tmp "]` → куски `0x82 [00, u32 offset, ≤176 байт]` во флаге **0x53 с номером пакета** (новый байт между флагами и длиной; декодер Ion это поддерживает) → close `0x83 [00, size, size, crc32]` → finish `0x84 [00]` → rename `0x87 "tmp>rgb"` на цель 0 → select `0x60 0x2d + u32 id`. Ответы: канал | 0x80, статус 0 = ok. `LightEffects.upload` воспроизводит захват байт в байт (тест).
- **Список**: `0x08 [00 00 "1|1|0:/light/diy|.rgb"]`, ответ: папка, число записей, у каждой имя `<id>.RGB`, размер и контрольная сумма.
- **В Ion**: шаблоны (`LightDesign`: один цвет, мигание, дыхание, градиент, бегущий огонь, радуга, половинки), до 9 своих эффектов с id `900000 + слот`, загрузка с прогрессом (MTU просим 247, куски ужимаются под MTU), список эффектов на колесе и их включение (`Control.LIGHT_PACKAGE`).
- **Повтор id ломает загрузку**: колесо отклоняет rename `.tmp>.rgb`, если `<id>.rgb` уже есть (первая сборка брала id = 900000 + слот и сломалась на повторной загрузке слота; на колесе остался недописанный `900001.tmp`, колесо показывает его как пустой эффект). Теперь перед каждой загрузкой Ion читает список и берёт id больше всех известных Ion-id (`LightDesign.nextId`), у дизайна хранится `wheelId` последней копии.
- **Удаление** (второй захват, `docs/evidence/light-delete-frames.txt`): `13 [02 00 04 86 "0:/light/diy/<id>.rgb "]`, ответ `12 [02 84 86 00]`. ФС не различает регистр. Листинг отдаёт и `.TMP` (недописанные загрузки), офф. приложение их скрывает, Ion помечает их `Stored.temporary`. Ion перед загрузкой удаляет свои `.tmp`, после сбоя удаляет созданный `.tmp`, после успеха удаляет прошлую копию дизайна. В «На колесе» любой эффект можно включить или удалить (с подтверждением), для недописанных есть кнопка «Убрать».
- **Редактор** (`LightEditor`): полноэкранный, светодиоды нарисованы там, где их рисует редактор InMotion (`LedLayout`: по 12 в боковых полосках, кольцо 2 × 23 с разрывами сверху и снизу, координаты сняты со скриншота офф. редактора). Кисть: палитра, «выключен» и свой цвет (оттенок/насыщенность/яркость); касание или проведение пальцем красит; заливка и гашение кадра, отмена (50 шагов), кадры с миниатюрами (до 60, «+ Кадр» копирует текущий), проигрывание, длительность кадра. Шаблоны стали отправной точкой: они заполняют кадры (градиент сверху вниз, бегущий огонь и радуга по кругу, половинки слева/справа). Нарисованные кадры хранятся в prefs восьмым полем (`Template.CUSTOM`, 6 hex на LED, кадры через запятую).
- **Порядок LED подтверждён владельцем на колесе**: `LedLayout.ORDER` = левая полоска, левая половина кольца, правая половина, правая полоска, каждая сверху вниз.
- **Экран**: «Боковая подсветка» — раскрывающаяся строка в группе фар (под яркостью). Выкл/музыка/скорость отправляются сразу; «Персонализированная» только открывает разделы «Мои эффекты» и «На колесе» (они видны, если выбран этот пункт или колесо уже в режиме 1). Новый эффект начинается с пустого кадра; свой цвет — квадрат насыщенность/яркость, полоса оттенка и HEX.
- **Превью эффектов на колесе**: есть только у загруженных из Ion (рисуется из дизайна с тем же `wheelId`). Файлы с колеса Ion не читает: команда чтения файла не захвачена, угадывать команды файловой системы не стали.
- Не проверено на колесе: кубическая кривая на других цветах, смысл «связи со скоростью».
